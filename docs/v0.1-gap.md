# v0.1 gap analysis

This table records what Crabscale v0.1 covers against the intended
**single-tailnet** scope, and what is deliberately out of scope for the
release. It is the canonical gap list referenced by M4-04 (#27); the same
content lives in the wiki as [Gap-Analysis](../crabscale.wiki/Gap-Analysis.md).

Legend:

- **Done** — implemented, tested, and documented.
- **Partial** — usable for v0.1 single-tailnet, with known limits.
- **Gap** — deliberately out of scope for v0.1.

## Core control plane

| Area | Status | Notes / reference |
|---|---|---|
| Auth-key registration | Done | `pre_auth_key` flow, salted hash only (Spec-Registration, `crabscale-policy`) |
| Interactive registration approval | Done | Long-poll approval + OIDC (Spec-Registration §7) |
| SQLite persistence + migrations | Done | File or in-memory store, versioned migrations (Architecture/Persistence) |
| Node map + lite updates | Done | Initial MapResponse and deltas (Spec-NetMap, M3-02/03/04) |
| Streaming map sessions + keepalive | Done | One writer task per session, bounded channel |
| Online/offline lifecycle | Done | Reconnect grace, ephemeral cleanup (M1-06) |
| Pre-auth key administration (CLI) | Partial | No dedicated `preauth` CLI subcommand; keys are configured via `--auth-key` |
| User/role administration | Partial | Single default user per tailnet; no user CRUD CLI |

## Policy and network

| Area | Status | Notes / reference |
|---|---|---|
| HUJSON ACL / grants compiler | Done | Per-node packet filters (Spec-Policy) |
| Tags, autogroups, node attributes | Done | Spec-Policy §4 |
| Subnet routes and exit nodes | Done | `crabscale route` CLI, approval model |
| MagicDNS + split DNS + search domains | Done | MapResponse DNS, hot-reload extra records |
| Tailscale SSH check mode | Done | `crabscale ssh` CLI + `/machine/ssh/*` |
| OIDC registration | Done | Discovery + code flow + profile upsert |

## Connectivity

| Area | Status | Notes / reference |
|---|---|---|
| TS2021 + Noise transport | Done | Spec-Transport |
| HTTP/2-over-Noise router | Done | `crabscale-server`, `serve_control_as` |
| Embedded STUN | Done | RFC 5389 binding responder |
| Embedded DERP relay (library) | Partial | `crabscale-derp` Relay + tests; the `/derp` upgrade listener is not yet wired into the server binary |
| DERP multi-node mesh | Gap | Out of scope; single-node relay only |
| Peer-to-peer / wireguard data plane | Gap | Control server does not carry node traffic |

## Operations (M4)

| Area | Status | Notes / reference |
|---|---|---|
| Capability version matrix | Done | M4-01, minimum 113, CI matrix |
| Security hardening / rate limits | Done | M4-02, `429` + `Retry-After`, bounded caches |
| TLS / reverse proxy / containers | Done | M4-03, rustls (files/ACME), trusted proxies, Docker |
| Backup & restore (no plaintext secrets) | Done | `crabscale backup` / `restore` (M4-04) |
| Metrics (`/metrics`, Prometheus) | Done | sessions, registrations, policy compiles, DERP packets (M4-04) |
| `/health`, `/version` | Done | M4-04 |
| Structured JSON logging | Gap | v0.1 uses `println!`/`eprintln!`; structured logging is deferred |
| Release CI + `CHANGELOG` | Done | tag `v*` workflow (M4-04) |
| Multi-tailnet / multi-tenant | Gap | Intentionally out of scope; single tailnet only |
| Production load guarantee | Gap | Supported scale documented; no SLO (Supported-Scale) |
